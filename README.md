# Chat of Azeroth

A chat window like Discord or mIRC for WoW Forever, by DinX. Works on its own, and fits the other "of Azeroth" add-ons (Casters of Azeroth's own chat module steps aside when this one is loaded).

## What it does

- **Rooms on the left**: All, System, Loot, Say and emotes, Guild, Party, Raid, Instance, every channel you are in (`# Trade`), and every whisper partner as their own conversation (`@ Name`, kept between sessions). Unread counts in bold, nothing blinks.
- **Messages in the middle**: time, clickable names in class colours, item and quest links.
- **Blizzard's own input box at the bottom**, set to the room you picked: you type and send every line yourself.
- **Your own tabs**: `+ New tab` — pick which kinds of messages (or just some channels) and optionally a word. Right-click a tab to change or delete it.
- **`+ Join channel`**: type a name and you are in.
- Movable, and bigger with the corner grip (more lines fit, the text keeps its size).

In combat or in instances Blizzard can hide chat text from add-ons: those lines are still shown, as they are, but can't be filtered.

## Commands

- `/cha`: settings
- `/cha toggle`: our chat window on or off (Blizzard's comes back)
- `/cha unlock` / `/cha lock`: move and resize
